Vansiora Privacy Policy

Last updated: 2026-06-10

Vansiora is a local browser extension for structured data formatting and viewing, password generation, encoding, hashing, signing, key derivation, and encryption utilities.

Single Purpose

Vansiora provides local browser tools that help users format and inspect JSON, XML, YAML, and TOML, generate passwords, and run common text encoding, hashing, HMAC, PBKDF2, and AES-GCM workflows.

Data Processing

Vansiora processes user input locally in the browser. JSON, XML, YAML, TOML, generated passwords, password settings, encryption keys, plaintext, ciphertext, encoded text, hash inputs, HMAC inputs, PBKDF2 inputs, and AES-GCM inputs are not sent to a server by Vansiora.

Vansiora does not operate a remote processing service for user input. The extension uses bundled extension code and browser APIs to perform parsing, formatting, password generation, hashing, signing, key derivation, and encryption workflows on the user's device.

Vansiora uses user data only to provide or improve its single purpose: local browser tools for structured data viewing, password generation, and encoding, hashing, key derivation, and encryption workflows.

Local Storage

Vansiora may store formatting history, language preference, and workspace convenience data locally in the browser through localStorage and IndexedDB. This data remains on the user's device and is used only to provide local history, language selection, and convenience features.

Vansiora does not use browser local storage for advertising, analytics, user profiling, or sale of data.

Web Page Access

Vansiora includes a content script that can run on web pages to detect raw JSON or XML documents and provide a structured viewer or an option to open the content in the extension. The content script runs locally in the browser and does not transmit detected page content to Vansiora servers.

The content script is designed to run only in the top-level frame and avoids replacing ordinary web pages. It acts only when the page appears to be raw JSON or XML data.

When necessary for XML or feed detection, the content script may read the current page content or make a same-origin request for the current page URL. This is used only to detect and display raw structured data locally. Vansiora does not send this page content to Vansiora-controlled servers.

Small page payloads may be transferred to the extension page through the browser URL hash. Larger payloads may be temporarily held in the extension background context so the extension page can read them. This transfer is local to the user's browser and is not sent to a Vansiora server.

Data Collection

Vansiora does not collect or transmit the following data to Vansiora servers:

  • Personally identifiable information
  • Health information
  • Financial or payment information
  • Authentication information
  • Personal communications
  • Location
  • Web history
  • User activity for analytics or advertising
  • Website content for remote processing

Vansiora does not use user data for advertising, analytics, behavioral tracking, creditworthiness, lending, or any purpose unrelated to the extension's single purpose.

Data Sharing

Vansiora does not sell, share, or transfer user data to third parties.

Vansiora does not transfer user data to advertising platforms, data brokers, information resellers, analytics providers, or other third parties. Vansiora does not operate a server-side support, analytics, or review system that allows Vansiora personnel or third parties to read user data stored locally in the browser.

Limited Use

Vansiora's use and transfer of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Vansiora does not use or transfer user data for personalized advertising, creditworthiness, lending, unrelated product purposes, or any purpose outside the extension's single purpose. Vansiora does not sell user data.

Vansiora does not collect or use web browsing activity except to the limited extent required for the user-facing raw JSON/XML detection feature described in the Chrome Web Store listing and extension interface. That page access is used locally to detect and display raw structured data and is not used for analytics, advertising, profiling, or unrelated browsing-history collection.

Analytics And Tracking

Vansiora does not include analytics, advertising trackers, behavioral tracking, affiliate tracking, or user profiling.

Remote Code

Vansiora does not load or execute remote code. Extension code is bundled with the published package.

Permissions

Vansiora does not declare extension permissions or host_permissions. Its content script is matched on web pages only to detect raw JSON/XML documents locally.

Vansiora exposes only the extension page and the 48px icon as web-accessible resources. These resources are used to open the local extension UI and display the inline viewer icon.

Trader Status

The current free local release is operated as a non-trader release. If Vansiora later adds paid licenses, subscriptions, commercial support, business-to-business distribution, or other trade/business/professional use, the Chrome Web Store trader status and related public disclosures should be updated before that commercial release.

Contact

For privacy questions, contact the extension publisher through the support contact configured in the Chrome Web Store developer account.
